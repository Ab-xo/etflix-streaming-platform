# EtFlix Streaming Platform

A cinematic movie and series discovery interface built with React. EtFlix demonstrates a polished streaming experience with curated content, filtering, search, pagination, responsive layouts, and animated interactions.

## Features

- Featured content and curated home sections
- Movie and series catalog browsing
- Search, filters, sorting, and pagination
- Genre discovery pages
- Responsive glassmorphism interface
- GSAP-powered transitions and interactions

## Technology

- React 18, React Router, Vite
- JavaScript, HTML, and CSS
- GSAP and ScrollTrigger
- ESLint and PostCSS

## Getting started

```bash
npm install
npm run dev
```

## Commands

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Roadmap

Potential next steps include persistent authentication, watchlists, a production movie API, recommendations, and video playback integration.
